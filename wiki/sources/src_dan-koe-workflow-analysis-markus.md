# Workflow "Learn to Figure Anything Out with AI" — Chi tiết từng bước

## Summary

Phân tích chi tiết workflow từ bài viết của Dan Koe, hệ thống hóa thành 4 focus areas: Brand, Content, Product, Promotions. Markus nhấn mạnh đây là meta-skill — cách tự tạo prompt từ expert resource thay vì dùng prompt có sẵn. Workflow gồm 5 bước cốt lõi: tìm expert resource, feed vào AI, extract action plan, biến thành AI coach prompt, rồi dùng nó. Mỗi focus area có các bước mini-workflow cụ thể với prompt mẫu. Điểm mấu chốt là mỗi ngưởi sẽ có system khác nhau vì strategy được cá nhân hóa qua Phase 1 interview.

## Key points

1. **Meta-skill cốt lõi:** Tự tạo prompt từ bất kỳ nguồn expert nào thay vì dùng prompt có sẵn
2. **Công thức 5 bước:** Tìm expert → Feed AI → Extract plan → Tạo prompt → Dùng
3. **Chuẩn bị tư duy:** AI không phải magic, intelligence needs context, có nhiều "cách đúng"
4. **FOCUS 1 — Brand:** 4 bước tạo coach (tìm expert → extract plan → tạo prompt 2-phase → dùng coach)
5. **Prompt 2-phase:** Phase 1 phỏng vấn để lấy context, Phase 2 làm coach hàng tuần
6. **FOCUS 2 — Content:** Generate 30 ideas → Break down high-performing content → Tạo content-generation prompt
7. **FOCUS 3 — Product:** 5 mini-workflows (tìm loại product → chọn topic → tạo offer → viết landing page → reverse-engineer competitor)
8. **FOCUS 4 — Promotions:** Học frameworks (PAS, AIDA) → Hiểu psychology → Tạo promotions cụ thể → Cycle and test
9. **Chiến thuật phân phối:** Link trong mọi YouTube description, reply 1 lần/ngày, guide về bio link
10. **Kết quả:** Chiến lược cá nhân hóa + expert coach trong ~30 phút, không tốn $10K
