# Orchestrator-Worker-Validator

## Definition

Multi-agent architecture pattern với 3 roles: Orchestrator (delegates), Worker (executes), Validator (reviews) — used trong Factory Missions system.

## Key ideas

- Orchestrator: Planning, delegation, coordination
- Worker: Task execution, tool calling
- Validator: Review, approval, quality control
- Clear separation of concerns
- Handoff protocols giữa agents
