# CoALA Framework

## Definition

CoALA (Cognitive Architectures for Language Agents) là research paper (Sumers, Yao, Narasimhan, and Griffiths, 2023) formalizes cognitive science concepts về memory cho LLM agents. Framework này mapping các loại memory từ cognitive psychology sang practical implementations trong AI systems.

## Key ideas

- Paper: "CoALA: Cognitive Architectures for Language Agents" (arXiv:2309.02427)
- Authors: Sumers, Yao, Narasimhan, Griffiths (2023)
- Core insight: agents có một working memory và nhiều optional long-term memories
- Phân loại memory dựa trên cognitive science: semantic vs episodic, declarative vs procedural
- Framework giúp practitioners identify which memory slot họ đang missing
- Foundation cho việc phân biệt 7 types of agent memory
