# How to remember everything you read

## Metadata

- **Author:** Dan Koe

## Summary

Bài viết challenge quan niệm phổ biến về việc cố gắng nhớ mọi thứ đã đọc. Dan Koe cho rằng nếu cần cố nhớ thì không quan trọng, và nếu quan trọng thì sẽ tự nhớ. Bài viết trình bày cybernetics learning model — learning là output process, không phải input process. Mục tiêu tạo error signal, error signal tạo filter, filter tạo relevance, relevance tạo retention. Key insight: đừng bắt đầu bằng việc học, hãy bắt đầu bằng việc hành động về phía mục tiêu.

## Key points

- Most people muốn nhớ mọi thứ để sound smart — unconscious status symbol
- Memorizing facts là least effective way để improve life situation
- Learning is a cybernetic process: reference signal (goal) → sensor (perception) → comparator (gap/error) → actuator (behavior)
- Goal creates error signal → error signal creates filter → filter creates relevance → relevance creates retention
- Most people fill mind with noise và things they will never use vì lack clear goals
- Learning là output process vì output demands input — hành động tạo context cho learning có meaning
- Schools teach input-based learning (memorize for tests), real life requires output-based learning
- Person conditioned for default path (school → job) won't notice money-making opportunities outside jobs
- To become obsessed: look at current actions và realize where life will end up if don't change
- Sit with that image, let potent emotion fill you, redirect toward better direction
- Life you want lies at end of series of meaningful projects
- Mind, body, relationships, finance = projects với structured goals và milestones
- Project creates frame for learning (filtering unimportant noise)
- When want to learn something new, don't start learning — take first step toward goal instead
- "Burn the boats" — extreme changes enhance neuroplasticity hơn nhiều small changes
