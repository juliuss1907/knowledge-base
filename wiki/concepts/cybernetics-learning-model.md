# Cybernetics Learning Model

## Definition

Cybernetics learning model áp dụng principles của cybernetics (Greek: kybernētēs = helmsman) vào learning process. Model này xem learning như một feedback system: goal là reference signal, current state là perception, gap giữa chúng là error signal, và actions để reduce error là learning. Learning không phải passive input mà active output-driven process.

## Key ideas

- Cybernetics stems từ Greek "kybernētēs" meaning steersman/helmsman
- Perfect image of feedback system: helmsman reads current state (wind, waves), compares với intended course, adjusts
- Four components: reference signal (goal), sensor (perception), comparator (gap/error), actuator (behavior)
- Giống thermostat: turns on heat when too cold, pancreas releases insulin when blood sugar rises
- Learning fails khi không có negative feedback loop — không có goal thì không có error signal
- Without goal, night of drinking doesn't register as problem vì không impact non-existent goal
