# Code as Substrate

## Definition

Code như một nền tảng (substrate) cho agent intelligence — executable, inspectable, stateful, verifiable — cho phép agent thực hiện reasoning, action, environment modeling và execution-based verification một cách đáng tin cậy.

## Key ideas

- **Executable:** Hành động trở nên cụ thể và có thể kiểm tra
- **Inspectable:** Các bước trung gian minh bạch
- **Stateful:** Tiến trình tác vụ được lưu trữ xuyên suốt các bước
- **Verifiable:** Tính đúng đắn có thể được kiểm chứng qua thực thi
