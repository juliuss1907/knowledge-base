# Alpaca API

## Definition

Commission-free stock and crypto trading API từ Alpaca Markets — nền tảng cho algorithmic trading và AI trading agents.

## Key ideas

- REST API cho orders, account data, market data
- Paper trading environment để test strategies
- WebSocket streaming cho real-time data
- Support stocks, ETFs, crypto
- Rate limits và usage quotas
