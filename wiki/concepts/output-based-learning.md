# Output-Based Learning

## Definition

Output-based learning là approach cho rằng learning là output process, không phải input process. Thay vì hoard material và cố absorb nó (input), bạn tạo output (projects, actions, implementations) và learning happens như byproduct. Output demands input — hành động tạo context cho learning có meaning và retention.

## Key ideas

- Traditional approach: focus on content, hoard material, absorb với spaced repetition, flashcards, courses
- Output-based: learning emerges từ việc cố gắng achieve something cụ thể
- Schools dạy input-based (memorize for tests), real life requires output-based
- "Don't start learning, take the first step toward the goal instead"
- Goal creates frame for learning → filter what matters → relevance → retention
- Most people fill mind with noise vì lack output/goals để filter
- Output creates necessity → necessity creates focus → focus creates retention
- Projects là structured set of goals và milestones — tạo frame cho learning
