# Multi-Agent Taxonomy

## Definition

Phân loại 5 mô hình giao tiếp cơ bản giữa các agent trong hệ thống multi-agent, từ đơn giản đến phức tạp.

## Key ideas

1. **Delegation:** Agent cha tạo agent con xử lý vấn đề cụ thể — đơn giản, phổ biến nhất
2. **Creator-Verifier:** Một agent thực hiện, một agent kiểm tra — loại bỏ "định kiến về chi phí" (sunk cost fallacy)
3. **Direct Communication:** Các agent nhắn tin trực tiếp — khó thực hiện do trạng thái dễ phân mảnh
4. **Negotiation:** Tương tác qua tài nguyên chung — hiệu quả khi đạt trao đổi cùng có lợi
5. **Broadcast:** Một agent gửi thông tin đến tất cả — then chốt duy trì tính nhất quán
