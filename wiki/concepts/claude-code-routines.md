# Claude Code Routines

## Definition

Scheduled routines trong Claude Code cho phép agent chạy tự động theo thời gian định sẵn — nền tảng cho 24/7 autonomous agents.

## Key ideas

- Routines trigger agent sessions tại specific times
- Dùng CLAUDE.md làm system prompt cho mỗi session
- Kết hợp với scripts/tools để thực thi tác vụ
- Essential cho trading agents, monitoring, scheduled tasks
