# AI Security Tools

## Definition

AI security tools là bộ công cụ và skills giúp AI agents thực hiện các tác vụ bảo mật ở mức chuyên gia — từ threat hunting, forensics, đến red teaming và AI security (LLM red-teaming, prompt injection defense). Anthropic Cybersecurity Skills cung cấp 14 AI Security skills dùng garak/PyRIT cho LLM red-teaming, MCP/agentic security, guardrails. Cùng với các domain khác (forensics, malware analysis, cloud security), các tools này biến generic LLM thành capable security analyst bằng cách cung cấp structured decision-making workflows thay vì chỉ tool commands.

## Key ideas

- **AI Security domain:** 14 skills — LLM red-teaming (garak/PyRIT), prompt injection, MCP/agentic security, guardrails
- **Domain phong phú:** 818 skills tổng, từ memory forensics (Volatility3) đến identity (ROADtools), red teaming (BloodHound, Sliver/Havoc C2)
- **Structured workflows:** When to Use · Prerequisites · Workflow · Verification — execution có thể kiểm chứng
- **Framework-mapped:** Mỗi skill map tới ATT&CK, CSF, ATLAS, AI RMF...
- **Agent-native:** Progressive disclosure giúp scan nhanh, load sâu khi cần
- **Sử dụng có trách nhiệm:** Authorized & lawful use only — offensive/dual-use chỉ cho testing được phép
