# Premature Analysis

## Definition

Phân tích trước khi có đủ ngữ cảnh (context). Trong môi trường dự án, áp lực phải hành động nhanh thường dẫn đến việc tạo spreadsheet, gán owner, xây dashboard, cập nhật timeline — tất cả trước khi hiểu rõ hệ thống. Kết quả: quản lý sai vấn đề một cách hiệu quả (managing the wrong problem more efficiently).

## Key ideas

- Áp lực trong project environment: tạo spreadsheet, gán owner, xây dashboard, cập nhật timeline — trước khi hiểu hệ thống
- Kết quả: "premature precision" — chính xác nhưng sai vấn đề
- "Without systems thinking, analysis can become premature precision."
- Systems thinking giúp phân tích trở nên hữu ích bằng cách cung cấp context trước
- "Systems thinking must come before analytical thinking because analysis needs context."
- Không phải bỏ phân tích — mà là cải thiện chất lượng phân tích
