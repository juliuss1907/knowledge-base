# Error Signal (Learning)

## Definition

Trong cybernetics learning model, error signal là gap giữa target state (goal) và current state (perception). Error signal là driver của learning — nó cho bạn biết bạn off track và cần adjust. Without error signal, không có learning vì không có awareness của gap.

## Key ideas

- Error signal = difference between target và current state
- Không phải "error" theo nghĩa mistake mà là deviation from intended course
- Goal creates error signal → error signal creates filter → filter creates relevance → relevance creates retention
- Without goal, không có error signal → không có filter → mind filled with noise
- Person without fitness goal: night of drinking không register as error
- Person with fitness goal: hangover = error signal requiring correction
- Error signal creates necessity → necessity drives learning
- Learning happens when correcting errors, not when consuming content
